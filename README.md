# iPhone 15 Website Clone

A high-end, interactive landing page for the iPhone 15 Pro, featuring advanced 3D models and smooth animations.

> [!IMPORTANT]
> **Project Purpose**: This project was developed as part of a modern web development course to explore 3D rendering and motion graphics using Three.js.
It demonstrates interactive 3D scenes, camera controls, lighting effects, and animated objects.
While initially created as course material, custom modifications and enhancements were implemented to practice real-world 3D web development techniques.

## 🚀 Features

- **Interactive 3D Models**: Explore the iPhone 15 Pro in detail using Three.js and `@react-three/fiber`.
- **Dynamic Animations**: Seamless transitions and scroll-triggered effects powered by GSAP (GreenSock Animation Platform).
- **Responsive Design**: Optimized for all devices using Tailwind CSS.
- **Custom Video Slider**: Interactive navigation through product feature videos.
- **Performance Optimized**: Built with Vite for a fast development and production experience.

## 🛠️ Tech Stack

- **Framework**: [React.js](https://reactjs.org/)
- **Bundler**: [Vite](https://vitejs.dev/)
- **3D Engine**: [Three.js](https://threejs.org/)
- **Animations**: [GSAP](https://greensock.com/gsap/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)

## 📦 Getting Started

### Prerequisites

- Node.js (Latest LTS recommended)
- npm or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone [repository-url]
   cd apple_website
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

## 📜 Available Scripts

- `npm run dev`: Starts the Vite development server.
- `npm run build`: Compiles the project for production.
- `npm run lint`: Checks for code quality issues using ESLint.
- `npm run preview`: Locally preview the production build.
